## STANDING RULE - NEVER PUT A PIPE IN A STATUS CELL

This has now stopped the relay twice in one evening, and the second time it was the
cycle FIXING this very bug that broke it, by quoting code containing a pipe in its own
status text.

The watcher splits each row on the pipe character and reads the status as the
second-to-last field. A row must therefore have EXACTLY 5 fields. One stray pipe -
even inside backticks - makes the row unreadable, the watcher refuses, and the whole
queue behind it stops.

When writing a status cell: no pipe characters. Use a forward slash instead. This
applies to Claude Code, to Cowork, and to every scheduled session.

### If you find an unreadable row, repair it with exactly this

It preserves the BOM, the line endings and the full text. Do not improvise a
different fix, and never delete or truncate a row.

    python3 - <<'REPAIR'
    import io,os,re
    P=os.path.expanduser("~/mnt/Bidlowprojects/BidlowClients/Opensdoors/ODoutreach/.bidlow/relay/QUEUE.md")
    s=io.open(P,encoding="utf-8-sig",newline="").read(); lines=s.split("\n"); n=0
    for i,l in enumerate(lines):
        if not re.match(r'^\| *\d+ *\|', l): continue
        f=l.split("|")
        if len(f)==5:
            st=f[-2].strip()
            if not re.match(r'^(TODO|DONE|IN PROGRESS|BLOCKED)', st):
                m=re.search(r'(TODO|DONE|IN PROGRESS|BLOCKED)', st)
                if m: f[-2]=" "+st[m.start():]+" "; lines[i]="|".join(f); n+=1
            continue
        lines[i]="|".join(["",f[1],f[2],"|".join(f[3:-1]).replace("|","/"),""]); n+=1
    if n: io.open(P,"w",encoding="utf-8",newline="").write("\n".join(lines))
    print("repaired",n,"row(s)")
    REPAIR
